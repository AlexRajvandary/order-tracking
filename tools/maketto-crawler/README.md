# Сборщик каталога Maketto.jp

Локальная консольная утилита открывает каталог Maketto.jp в Chromium, переходит по страницам и сохраняет товары в JSON, совместимый с импортом Product API.

## Установка

```powershell
cd C:\Users\stark\Documents\order-tracking\tools\maketto-crawler
npm install
npm run install-browser
```

## Запуск

```powershell
.\run.ps1 -Url "https://maketto.jp/ru/catalog?store=rakuten&category=101070" -Pages 5
```

По умолчанию категория или поисковый запрос автоматически добавляются в имя файла. Например, для запроса «кимоно» результат появится в `output/maketto-products-кимоно.json`. Для URL с `category=101070` сборщик возьмёт название категории из данных Maketto; если сайт его не вернёт, использует запасное имя `категория-101070`.

Свой путь к файлу:

```powershell
.\run.ps1 -Url "https://maketto.jp/ru/catalog?store=rakuten&category=101070" -Pages 10 -Output "C:\temp\watches.json"
```

Даже при собственном имени файла категория будет добавлена перед расширением, например `C:\temp\watches-кимоно.json`.

Можно запускать и напрямую через Node.js:

```powershell
node .\src\index.mjs --url "https://maketto.jp/ru/catalog?store=rakuten&category=101070" --pages 5
```

Дополнительные параметры:

- `--delay 1200` — задержка между страницами в миллисекундах;
- `--timeout 60000` — время ожидания страницы или ответа сайта;
- `--headful` — показать окно браузера; crawler прокрутит страницу к видимой кнопке с иконкой `#next-arrow`, подсветит её и нажмёт;
- `--category "Часы"` — принудительно назначить категорию всем товарам;
- `--parent-category "Аксессуары"` — дополнительно назначить родительскую категорию;
- `--help` — показать справку.

Количество в `--pages` означает число страниц, которые надо обработать, начиная с открытой по URL страницы. Утилита останавливается раньше, если следующей страницы нет.

Каждый лог начинается с количества секунд от запуска. Во время долгого ожидания раз в 5 секунд выводится строка таймера с текущей операцией.

Файл перезаписывается после каждой обработанной страницы. При ошибке или ручной остановке через `Ctrl+C` уже найденные товары сохраняются в тот же JSON, а в `source.incomplete` и `source.stopReason` записывается причина незавершённого обхода. Повторяющиеся товары удаляются по SKU.
