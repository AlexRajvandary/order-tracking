# Разборы инцидентов

В этой папке хранятся технические разборы сбоев, которые затронули production или могли повлиять на доступность системы. Цель раздела — сохранить не только итоговое исправление, но и ход диагностики, безопасный способ восстановления и меры против повторения.

## Список инцидентов

|---|---|---|---|---|
| 14.08.2026 | [INC-2026-08-14-001](./INC-2026-08-14-001-crawler-claim-concurrency.md) | Product API / crawler-worker | Product API отвечал `500` при получении задания crawler из очереди | Исправлено в коде |

## Что должно быть в разборе

Каждый документ должен содержать:

1. понятное описание симптомов и влияния;
2. подтверждённую первопричину без персональных данных и секретов;
3. хронологию диагностики;
4. описание исправления;
5. безопасные команды проверки и восстановления;
6. меры, снижающие вероятность повторения.

В разборы нельзя помещать пароли, API-ключи, содержимое `.env`, персональные данные клиентов и полные production-дампы.
